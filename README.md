# School SMS (Lite)
Next.js + TypeScript + Tailwind + Supabase.

## Roles
| Role | Job |
|---|---|
| Principal | School oversee (academic); fees/students overview |
| Finance | Students, fees, invoices, receipts, collect cash, salaries |
| Teacher | Attendance / marks / timetable |

## Setup
1. Clone repo, then `npm install`
2. Create `.env.local` 
3. Supabase SQL: `supabase/schema.sql` + needed `supabase/migration_*.sql`
4. `npm run dev` → http://localhost:3000
